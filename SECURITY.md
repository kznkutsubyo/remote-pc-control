# Security Policy

PC Phone Remote is intended for explicit, authorized control of your own Windows PC.

## Safe Defaults

- Do not expose `pc-phone-remote/app.py` directly to the public internet.
- Change the default PIN before real use.
- Use HTTPS for relay mode.
- Use a long random `RELAY_AGENT_TOKEN`.
- Keep relay access limited to your own devices.
