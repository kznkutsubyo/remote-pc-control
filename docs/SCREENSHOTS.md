# Скриншоты для README

Нужны скриншоты установленной версии 2.2 с настоящего телефона. Пришли PNG без обрезки и рамок; желательно один язык интерфейса и одинаковая ориентация экрана.

## Основной набор

| Имя файла | Что снять |
| --- | --- |
| `phone-remote-dark.png` | Пульт в тёмной теме, выбранный ПК, успешно загруженные показатели CPU/памяти и кнопки управления |
| `phone-studio.png` | Studio с тачпадом и основными действиями; если всё не помещается, второй кадр после прокрутки |
| `phone-transfer.png` | Обмен с одним-двумя демонстрационными файлами и короткой безопасной заметкой |
| `phone-settings.png` | Настройки: список устройств и оформление; при необходимости два кадра |
| `phone-remote-light.png` | Тот же пульт в светлой теме, чтобы показать оба режима |

Для первого экрана README достаточно пульта в тёмной теме, Studio и обмена. Остальные кадры подходят для раздела оформления и настроек.

## Дополнительно

- Тот же пульт с другой цветовой схемой, например мятной или синей.
- Окно добавления устройства с пустыми полями.
- Короткая запись экрана, если хочется показать анимации. Для основного README она необязательна.

## Подготовка

1. Назови демонстрационное устройство `Home PC` или `Gaming PC`.
2. Убери уведомления и закрой окна ошибок. На пульте сначала обнови подключение.
3. Скрой реальный IP/адрес relay, PIN, имя учётной записи Windows, SID, QR-коды и коды привязки. Эти данные не должны попадать в публичный репозиторий. Присылай уже очищенные кадры, если на них есть секреты.
4. Используй нейтральные имена файлов и текст, например `Example.txt` и `Hello from my phone`.
5. Не снимай пароль или процесс его ввода. Скриншот успешного входа сам по себе не подтверждает надёжность компонента.

Итоговые изображения размещаются в `docs/screenshots/`. Текущие два изображения в README относятся к прежнему интерфейсу и будут заменены после получения новых кадров. Отсутствующие изображения не подключаются заранее.
